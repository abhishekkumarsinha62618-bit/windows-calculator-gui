# Windows Calculator (Python Tkinter)

A fully functional desktop calculator application built using Python and Tkinter with custom styling and error handling.

## Features
- **User Interface:** Clean layout designed with custom fonts and button padding.
- **Operations:** Supports addition, subtraction, multiplication, division, and percentage calculations.
- **Error Handling:** Gracefully handles invalid mathematical expressions by displaying an error state.
- **Custom Branding:** Includes a custom window icon using Pillow (`PIL`).

## Technologies Used
- Python 3
- Tkinter (GUI Framework)
- Pillow (Image Processing)
